# Hallmarkによる家計簿UIの変更と検証

日付:2026-10-25

## 対象と方針

認証後のページファイル48件とログインを対象に、共通の見た目・操作部品を整備し、今日・明細・分析・設定／入力・口座や予定などの補助画面のまとまりを改善した。既存の配色選択、明暗表示、整数円、日付計算、保存・照合のロジックを引き継ぐ。

- 今日:今日使える額を主役にし、予定と貯金を補助領域へ。スマホの読む順序は維持。
- 明細:月の支出を先頭へ、収入と収支を補助値に整理。日付ごとの折りたたみ行は約65px間隔で一覧性を保つ。
- 分析・目標:状況、カテゴリ、ペース、次の行動、詳細の順序を保ち、広い画面では二列に配置。
- 設定・入力:関連項目とフォームをまとめ、フォーカス・ラベル・入力境界を明確化。
- 口座・予定・お知らせ・朝配信・初期設定:同じ面と余白、一覧・フォームの構造を適用。

## 保持確認

同じローカルQAデータで変更前後を比較。記録したリンク57/57、入力項目18/18、ハンドラ376/376、見出し27/27、表示数値28/28を保持した。転送専用ルートを含め、ルートを削除していない。

データ取得、保存アクション、金額や予測の計算、認証処理、DBスキーマには変更を加えていない。

## 文言の表示変更

- 「明日からN日の目安 · 休日 約A円 · 平日 約B円」から、同じ3項目を別行へ分離。数値と意味は同じ。
- 装飾の「→」「›」は、文言とリンク先を保ってaria-hiddenの線画アイコンへ変更。
- 「確認(N件) — 反映するものにチェック」などの区切りをコロンへ変更。実際の項目や件数は同じ。

実機のカメラ／OS写真選択の権限と、本番の個人データによる操作はこのデザイン変更では再確認していない。検証用の画像・金額をアプリの実データとして追加していない。
