# 予測の計算式(現在の実装)

数字はコードの定数(`src/domain/forecast/` 配下)。変えたときはこの文書も直す。

## 全体の流れ

着地 ＝ 決まっている額 ＋ 残りの変動費 ＋ 規則的な来店 ＋ 特別費(ここから乱数で 2,000〜10,000 通り試す)

```
着地(試行 t) = 実績
             + 予定
             + 固定費(確認済みのサブスク)
             + [ 変動費(t) + 来店(t) + 特別費(t) ] × 中心の補正係数
```

- 見出しは、この試行の平均。
- 幅は、10 回中 8 回(10〜90 パーセンタイル)の範囲。
- 範囲(目標のジャンルだけ、特別費を除く、など)で、先に明細を絞る。

## 1. 明細の分け方(`decompose`)

- **実績**: 期間内の今日までの通常支出(振替・対象外・入力待ちを除く)。
- **予定**: 今日より先の日付の通常支出。
- **固定費**: 確認済みのサブスクが、残り期間に何回来るか × 金額。
- **特別費**: 種別が特別のもの、またはそのカテゴリで上位 1% の金額(記録が 20 件以上のとき)。
- **変動費の学習用データ**: 上記以外の通常・実績。固定費、「予測を止める」にしたジャンル、規則的に通う店は除く。
- **直近のペース**: 直近 14 日の、学習用データの 1 日あたりの平均(表示用)。

## 2. 変動費のモデル(`model`、カテゴリごと)

**重み**: 直近を重く見る。

```
w(日) = 0.5^(経過日数 ÷ 半減期)
```

半減期は 30・90・180 日から、本人の過去の月での検証で選ぶ。検証できないときは 90 日。

**回数**: カテゴリ c の 1 日あたりの回数 λ を、ガンマ分布で推定する。

```
λ ~ Gamma( α = 全カテゴリの平均率 × 7 + Σ w·回数,  β = 7 + Σ w )
```

7 日分の事前情報を持ち、観測が増えるほど自分の値に寄る。季節係数がある月は、その分を取り除いた回数で学習する。

**1 回の金額**: 対数正規分布 `ln(金額) ~ Normal(μ, σ²)`。

```
μ = 全カテゴリの平均 + 件数/(件数+1) × (自分の平均 − 全カテゴリの平均)
σ² = 自分の分散(5件未満なら 0.49)  最小 0.05
     − 休日/平日で説明できる分
```

金額の事前情報の強さは「1 件分」。高額なカテゴリが引き下げられないよう、弱くしてある(ADR-069)。

**休みの日(土日祝)と平日の金額差**(ADR-070)

```
δ = 少ない方の件数/(少ない方の件数+6) × (休日の ln平均 − 平日の ln平均)   -1.2〜1.2
```

休日の金額: `μ + (1−休日割合)·δ`、平日の金額: `μ − 休日割合·δ`。

**曜日・給料日・祝日の係数(回数に掛ける)**

```
係数 = 1 + 日数/(日数+30) × (その条件の率 ÷ 全体の率 − 1)
```

30 日分の事前情報で、1.0 に寄せる。

- 曜日は 7 通り。
- 給料日は、給料日から 3 日間。
- 祝日は、ハッピーマンデー・春分秋分・振替休日・国民の休日まで含む。

**季節(月ごと)**

- 記録のそろった月が 12 か月以上あるときだけ使う。
- `月の1日平均 ÷ 全体平均` を、年数が少ないほど 1 に寄せて、0.6〜1.6 に収める。

## 3. 残りの期間の乱数(`simulate`)

試行ごとに、次を引く。

**水準の不確かさ**

```
水準 = exp(σ·z − σ²/2)     σ = 0.15 × √(30 ÷ 記録日数)   0.05〜0.6
```

全カテゴリの率に共通で掛ける。記録が短いほど幅が広がる。

**カテゴリごとの変動費**

```
λ' ~ Gamma(...)   μ' ~ Normal(μ, σ²/件数)
回数(休日) ~ Poisson( λ' × 水準 × Σ休日の各日の係数 )
回数(平日) ~ Poisson( λ' × 水準 × Σ平日の各日の係数 )
金額 ~ 対数正規。回数ぶん引いて足す
```

各日の係数は、曜日 × 給料日 × 祝日 × 月の季節。

**規則的な来店**

- 条件: 同じ店に 5 回以上、間隔 2〜40 日、間隔のばらつきが 25% 以内。
- 次回は「最後の来店 ＋ 間隔」の日に置く。
- その日に来る確率: `0.92 − 1.2 × ばらつき`(0.5〜0.92)。
- 金額: その店の対数正規分布。

**特別費**: `回数 ~ Poisson(1日あたりの発生回数 × 残り日数)`、金額は過去の特別費から無作為に選ぶ。

## 4. 検証による補正(`backtest` / `calibration`)

本人の過去 6 か月(完了月)を、月の 1・3 日目、半ば、残り 2 日の 4 時点で予測し直して、実際と比べる。

- **半減期**: CRPS(確率予測の誤差。小さいほど良い)が最小のものを選ぶ。
- **中心の補正**

  ```
  r = Σ(実際 − 決まっている額) ÷ Σ(予測の中央値 − 決まっている額)
  係数 = 1 + 件数/(件数+8) × (r − 1)     0.75〜1.4
  ```

  残りの支出(変動費・来店・特別費)にだけ掛ける。
- **幅の補正**: 補正後の外れ方 `|実際 − 中央値| ÷ 帯の半幅` の 80% 分位を、帯に掛ける(0.5〜3 倍)。
- 検証が使えるのは、完了月が 1 か月以上あるとき。

## 5. 画面に出る数字

- **着地の見込み**: 試行の平均。
- **10 回中 8 回**: 10〜90 パーセンタイル(幅の補正後)。
- **予算に収まる確率**: 試行のうち、予算以下だった割合。
- **ジャンルごとの「超える確率」**: `P(決まっている額 ＋ そのジャンルの試行 > 目標)`。
- **1 日の上限**: 変動費に係数 k を掛けたとき、収まる確率がちょうど 80% になる k の二分探索。
- **グラフの予測線**: `今日の実績 ＋ 残りの中央値 × (経過日数 ÷ 残り日数) ＋ 予定の段差`。帯は日数の平方根で広げる。

## 今の限界

- 外食の中の「居酒屋とランチ」のように、店の種類は見ていない。休日か平日かだけで金額差を見る。
- 記録が 15 日ほどだと、曜日・休日・給料日の係数と、休日の金額差は、ほぼ 1(効果なし)に寄る。
- 乱数のシードは、期間と明細の版から決まるので、同じデータなら毎回同じ数字になる。
