# デザイン仕様書にない機能の行き先(ADR-090〜104)

デザイン仕様書「家計簿 リデザイン」を絶対の仕様として画面を作り直した。2版目(ADR-091)で動線を
単純にした:ナビは 今日・明細・分析 と 記録する(＋)。旧「見通し」は「分析 › 目標」にまとめ、分析は
「目標」と「月のふりかえり」の2つ。カテゴリのマークは、どこで押してもそのカテゴリ(⑦)が開く。
目標の数字を変えるのは ⑥今期の目標 と ⑦カテゴリ だけ。記録(＋)でできるのは 記録する・カテゴリを足す・
固定費にする の3つだけ。

仕様書の画面にない機能は、次のどれかにした。

- **移した**:仕様書のほかの画面か、仕様書の行・ボタンの先(シート・下の階層)に置いた。
- **残した(仕様書の外)**:仕様書の画面の外(「…」のメニューなど)に置いた。
- **なくした**:画面から外した。復活させるときの手がかりとして、外す前のコミットを書いておく
  (1版目の前 `93fb40c`、2版目の前 `4fe1441`)。

## 画面の動線(2版目)

| 仕様書                 | アプリ                                                 | 開き方                                      |
| ---------------------- | ------------------------------------------------------ | ------------------------------------------- |
| ① 今日                 | `/`                                                    | ナビ                                        |
| ③ 明細                 | `/spending`                                            | ナビ                                        |
| ④a 分析 › 目標         | `/reports`(旧 `/plan` はここへ転送)                  | ナビ「分析」、今日の「今期の見通し」        |
| ④b 分析 › 月のふりかえり | `/reports/month`                                       | 分析の「月のふりかえり」                    |
| ⑤ 記録する             | ＋のシート                                             | ナビの＋                                    |
| ⑥ 今期の目標           | `/plan/edit`                                           | 分析 › 目標 の「編集」                      |
| ⑦ カテゴリ             | どの画面からも開くシート                               | カテゴリのマーク、⑥の行、次の一手のボタン   |
| ⑧ カテゴリの設定       | `/settings/categories`                                 | ⑥「カテゴリの設定」、「…」› カテゴリ         |

## 2. 残した(仕様書の外に置いた)

| 機能                                            | 場所                                                       | 理由                                                   |
| ----------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------ |
| 話して・文字で記録                              | 「…」› 記録する                                            | 記録(＋)は3つだけにするため、＋の外へ                |
| CSVを取り込む・メールを貼り付ける・突き合わせ・口座 | 「…」› 記録する                                         | 仕様書の画面にない                                     |
| そのほかの分析(`/reports/more`)              | 「…」› 振り返る                                            | 仕様書の分析にない分析をなくさない                     |
| カテゴリの詳細(取引・品目・店・ルール)        | ⑦「名前・マーク・色」→ カテゴリの設定の中のリンク       | ⑦では足りない、明細の付け替え・ルール                  |
| 日付で絞り込み中のチップ・「この日に手で記録」  | 明細(カレンダーで日付を押したときだけ)                   | 絞り込みを解除できるように                             |
| 二重に入っていそうな明細の知らせ                | 明細(あるときだけ)                                       | 重複に気づけるように                                   |
| 「今月へ戻る」                                  | 明細・月のふりかえり(ほかの月を見ているときだけ)         | 月の切り替えが遠くまで行ったとき                       |
| 期間の変更                                      | ⑥「期間」の行 → シート                                    | 仕様書は行だけ。押した先は仕様書にない                 |
| 目標が無いときの目標づくり・終わった目標のふりかえり | 分析 › 目標(目標が無い・終わったとき)                    | 仕様書は目標がある状態だけ                             |
| 色のテーマ(50色)                              | 「…」› 色                                                 | 仕様書の色は「ブラウザに合わせる」の既定の色           |
| レシート名(ADR-092)                           | ⑤記録する(金額・日付の下)                               | 本人の指摘。明細の名前(店名)を入れられるように       |
| 以前の「最近の支出の勢い」のグラフ(ADR-092)  | 分析 › 目標「ペース」(仕様書の棒グラフの代わり)         | 本人の指摘。平均の線・点線・金額が読める以前の形がわかりやすい |
| カレンダーの「出す / 隠す」と「週 / 月」を覚えておく(ADR-093 → 121) | 明細のカレンダー(既定で出す、この端末の cookie) | 本人の要望。開くたびに閉じたり週に戻ったりしないように |
| 10回中8回の幅の金額(ADR-094)                 | 分析 › 目標「いまの状況」の着地見込みの下 | 本人の指摘。帯がどこからどこまでかを数字で |
| AIボタン(ADR-103)                             | 下のメニューの4つめ(今日・明細・分析・AI)、シートで会話 | 本人の要望。記録から画面の案内まで会話で。登録は確認カードを通す |
| 今日の目安 56px・日付は「今日」の横(ADR-104)  | ①今日 | 本人の指摘。仕様書は 68px、日付は「今日」の上の行 |
| AIの「もう一度送る」と記録の案の「直す」(ADR-105) | AIのシート(送れなかった発言の下、確認カードの各行) | 本人の要望。直す画面は記録すると同じ(右上は「完了」) |
| AIの答えはホームと同じ数字(ADR-106) | AIのシート(今日の目安・今期の見通し・月末に残る見込みを根拠に答える) | 本人の指摘。AIが旧ホームの集計で答えていた |

## 3. なくした(画面に出なくなった)

### ホームに出すカテゴリを手で選ぶのをやめたとき(ADR-117)で外したもの

- ⑧カテゴリの設定の「ホームに表示」と「そのほか」の分け方と、各行のスイッチ(1つの一覧にした)。
- ⑦カテゴリの「ホームに表示」のスイッチ、AIの「ホームに出すかを変える」道具。

### 旧「手入力」の画面(`/transactions/new`)をまとめたとき(ADR-096)で外したもの

- 画面そのもの。`/transactions/new` は明細へ移って「記録する」を開く(`?date=`・`?type=income` は引き継ぐ)。
  「…」› 記録する の「くわしく入力」もなくした(手で記録するのは＋だけ)。
- 「いつもの」の候補、最近使った店の候補、金額の電卓と税込の計算、品目を1つずつ打ち込む入力、「目標の扱い」
  (選べるのは「目標の予算に含める」だけだった)。品目は、記録したあと明細の行を開いて「レシートを読み込む」で付けられる。
- 保存したあと続けて次の1件を入れる動き(＋は保存すると閉じる)。

### 2版目(ADR-091)で外したもの

- 見通しの「すべての支出 / 変えられる支出だけ」の切り替えと、「累計 / 日別」の切り替え(日別の棒グラフ)。
- グラフの上振れの金額と10回中5回の濃い帯(「10回中8回は X〜Y」の1行は、分析 › 目標の着地見込みの下に戻した、ADR-094)。
- 記録するの「メモ」の入力(明細の行を開いて書ける)。店名は「レシート名」として戻した(ADR-092)。
- ⑦の「へらした分だけ総額も下げる」スイッチ(⑥の「総額を固定」で決める)と、「判定(見直し候補 · 94%)」の行。
- 次の一手から、カテゴリの詳細ページへのリンク(⑦を開く)。

### 1版目(ADR-090)で外したもの

- ①今日:「今日使った額」の1行、10個の点と確率の文、見通しのバッジから開いた「カテゴリ別の超過」、
  「目標に入っていない」の1行、「目安」のバッジ。
- ③明細:集計カードの先月同日比・月末の見込み・「手取りを入れる」・固定費と変えられる支出、月の累計のグラフ、
  「概要 / 明細」の切り替え、カレンダーの週送り・目標期間の帯・「少〜多」の凡例、カテゴリ別の月の目安と
  「今月 / 目標期間」の切り替え。
- ④分析:「今月の収支」の月末の見込み(①今日の「貯金」に出る)。
- ⑥今期の目標:配分の「AIに相談」(代わりに「提案」)、好きな期間で次の目標を作る(予約は引き継ぎだけ)。
- ⑧カテゴリの設定:アイコンの丸(頭文字の丸にした。アイコン・色はカテゴリを開くと変えられる)。
