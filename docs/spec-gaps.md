# デザイン仕様書にない機能の行き先(ADR-090)

デザイン仕様書「家計簿 リデザイン」(①今日 ②見通し ③明細 ④分析 ⑤記録する ⑥今期の目標 ⑦カテゴリの目標額
⑧カテゴリの設定)を「絶対の仕様書」として画面を作り直した。仕様書の画面にない機能は、次のどれかにした。

- **移した**:仕様書のほかの画面か、仕様書の行・ボタンの先(下の階層)に置いた。
- **残した(仕様書の外)**:仕様書の画面の外(「…」のメニュー、記録するシートのいちばん下)に置いた。
- **なくした**:画面から外した。復活させるときの手がかりとして、外す前のコミット `93fb40c` を書いておく。

## 1. 移した(使える)

| 機能                                                   | 前の場所              | いまの場所                                       |
| ------------------------------------------------------ | --------------------- | ------------------------------------------------ |

## 2. 残した(仕様書の外に小さく置いた)

| 機能                                            | 場所                                                     | 理由                                                |
| ----------------------------------------------- | -------------------------------------------------------- | --------------------------------------------------- |
| 何枚か続けて撮る                                | ⑤記録するのいちばん下のリンク                            | 仕様書の「レシートを撮る」は1枚。連続撮影をなくさない |
| 話して・文字で記録                              | 同上                                                     | 仕様書にない入力のしかた                            |
| スクショから記録                                | 同上                                                     | 同上                                                |
| くわしく入力(口座・品目・返金・特別費・電卓) | 同上(`/transactions/new`)                              | 仕様書の手入力は口座を選べない(1つめの口座に入る)  |
| 日付で絞り込み中のチップ・「この日に手で記録」  | ③明細(カレンダーで日付を押したときだけ)                | 絞り込みを解除できるように                          |
| 二重に入っていそうな明細の知らせ                | ③明細(あるときだけ)                                    | 重複に気づけるように                                |
| 「今月へ戻る」                                  | ③明細・④分析(ほかの月を見ているときだけ)              | 月の切り替えが遠くまで行ったとき                    |
| 期間の変更                                      | ⑥今期の目標「期間」の行 → シート                        | 仕様書は行だけ。押した先の画面は仕様書にない        |
| 色のテーマ(50色)                              | 「…」› 色                                               | 仕様書の色は「ブラウザに合わせる」の既定の色にした  |

## 3. なくした(画面に出なくなった)

### ①今日

- 「今日使った額: N円」の1行(「なぜこの額？」の内訳には残る)。
- 10個の点と「毎日この額までなら、X%の確率で予算内に収まります」「確率はモンテカルロ法により算出」。
  予算内の確率は「今期の見通し」と②見通しに出る。
- 見通しのバッジを押すと出た「カテゴリ別の超過」のシート。
- 「目標に入っていない: 〇〇 N円」の1行。
- 「目安」のバッジ(記録が少ないときは「今日使える目安(記録が少ないので仮)」と言葉で出す)。

### ②見通し

- 「月末の支出」の見出しの「予算に収まる確率(モンテカルロ法)」の1行(確率は専用のカードへ)。
- グラフの「先月の線」「週・月の単位」の切り替え(③のカテゴリの詳細には残る)。
- なぜの「直近2週間は1日 約X円、この先は1日 約Y円で見ています」の説明。
- 最近の勢いの7日・21日の移動平均の線(平均は数字で出す)と、ツールチップ。
- AIの読み(「X月X日時点の読み:中央 約X円」)の1行。全文は「全文とレポート」(`/reports/ai`)にある。
- 次の一手のカード(①今日だけに出す)。

### ③明細

- 集計カードの先月同日比・月末の見込み・「手取りを入れる」・固定費と変えられる支出の内訳。
- 月の累計のグラフ(全体の着地は②見通し)。
- 「概要 / 明細」の切り替え。
- カレンダーの週送り(‹ ›)・目標期間の帯・「少〜多」の凡例(「月で見る」で月全体を見る)。
- カテゴリ別の行の月の目安(「使った額 / 目安」)と「今月 / 目標期間」の切り替え。

### ④分析

- 「今月の収支」の行の月末の見込み(①今日の「貯金」に出る)。
- 「着地の見込みは見通しへ」のリンク。

### ⑥今期の目標

- 総額とカテゴリへの配分の「AIに相談」(配分の提案)。代わりに仕様書の「提案(見直し候補を20%へらす)」。
- 好きな期間で次の目標を作る(予約は「この目標を引き継いで作成」だけ)。目標が無いときの②見通しには残る。

### ⑤記録する

- 記録のしかたを選ぶメニュー(カメラで撮る・写真から選ぶ・手入力の3枚と、下の一覧)。仕様書のシートに置き換えた。

### ⑧カテゴリの設定

- カテゴリのアイコンの丸(頭文字の丸にした。アイコン・色はカテゴリを開くと変えられる)。
