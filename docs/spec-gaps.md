# デザイン仕様書にない機能の行き先(ADR-090〜104)

デザイン仕様書「家計簿 リデザイン」を絶対の仕様として画面を作り直した。2版目(ADR-091)で動線を
単純にした:ナビは 今日・明細・分析 と 記録する(＋)。旧「見通し」は「分析 › 目標」にまとめ、分析は
「目標」と「月のふりかえり」の2つ。カテゴリのマークは、どこで押してもそのカテゴリ(⑦)が開く。
目標の数字を変えるのは ⑥今期の目標 と ⑦カテゴリ だけ。記録(＋)でできるのは 記録する・カテゴリを足す・
固定費にする の3つだけ。

仕様書の画面にない機能は、次のどれかにした。

- **移した**:仕様書のほかの画面か、仕様書の行・ボタンの先(シート・下の階層)に置いた。
- **残した(仕様書の外)**:仕様書の画面の外(設定の画面など。もとは「…」のメニュー、ADR-127 で設定にした)に置いた。
- **なくした**:画面から外した。復活させるときの手がかりとして、外す前のコミットを書いておく
  (1版目の前 `93fb40c`、2版目の前 `4fe1441`)。

## 3. なくした(画面に出なくなった)

### 動線と画面の整理(ADR-127)で外したもの

外す前のコミット `bd2fbef0`。古いURLは、まとめた先の画面へ送る(ブックマークが行き止まりにならない)。

- 今日の画面の「…」のメニュー(設定の歯車に。中身は設定の画面と＋のメニューに分けた)。
- 投資・副業・転職準備の画面とリンク(本人は「使っていない」。データは消さずに残す。`/investments`・
  `/side-hustle`・`/job-change` は設定へ送る)。
- 別々の画面だったもの:AI機能・パスワード・給料日(設定の中へ)、メールを貼り付ける・請求突合(「メールから
  取り込む」1つに)、話して・文字で記録(AI のタブへ)、レシートを確認・重複の確認(「確認が必要」へ)、
  そのほかの分析・カテゴリ分析・回数と1回の金額・月ごとの表・ちりつも(分析と月のふりかえりへ)。AIレポートの画面も
  一度まとめたが、日次・タイプ診断・アドバイス・見込みの読み・前の月が見られなくなったため戻した(ADR-128)。
- 記録するシートの「ほかの入力方法」(入口は＋のメニュー)。
- 戻るの書き方のばらつき(「戻る」「やめる」「一覧へ戻る」「→」)。戻るは「‹ 前の画面の名前」と、入力をやめる
  画面の「キャンセル」だけ。画面の文言の「ホーム」は「今日」にそろえた。

### ホームに出すカテゴリを手で選ぶのをやめたとき(ADR-117)で外したもの

### 旧「手入力」の画面(`/transactions/new`)をまとめたとき(ADR-096)で外したもの

- 画面そのもの。`/transactions/new` は明細へ移って「記録する」を開く(`?date=`・`?type=income` は引き継ぐ)。
  「…」› 記録する の「くわしく入力」もなくした(手で記録するのは＋だけ)。
