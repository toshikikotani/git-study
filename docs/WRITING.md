# 言葉のルール(N5、ADR-065)

このアプリが画面に出す文言(見出し・本文・ボタン・トースト・AIが生成する文章)が
守るルール。既存のコードにも一部すでに実践されていた慣習(`src/domain/money.ts`・
`src/domain/spending-plan.ts` のコメント参照)を、ここで明文化する。

## 1. 責めない(no blame words)

- 「浪費」「無駄」「失敗」「使いすぎ」のような、本人を評価・断罪する言葉を
  ユーザー向けの文言に使わない。内部のドメイン名(`wasteYen`・`WasteRatioTrend`
  のような変数・型の名前)まで変える必要は無いが、**画面に出す文字列**は
  中立的な言い方に置き換える。
  - 既存の実例:`app/(app)/spending/insights-card.tsx` は「浪費」を常に
    「見直し候補」と表記する(コミットB決定6、ADR-061)。同じ言い換えを
    `src/components/ui/waste-ratio-bars.tsx`・`app/(app)/reports/ai/report-view.tsx`
    にも広げた(N5でこのルールを明文化した際に、残っていた「浪費傾向のタイプ」
    →「支出傾向のタイプ」、「浪費比率」→「見直し候補の比率」に直した)。
  - AI生成レポート本文(`src/prompts/*.ts`)は対象外(このドキュメントの
    「4. 適用範囲」参照)。プロンプト自体は既に非難的な言い方を避けるよう
    指示している(例:`daily-report.ts`「浪費傾向のタイプを断定しない」)。
- 超過・失敗した記録そのものを隠したり嘘をつく必要は無い。**事実は正確に**、
  ただし評価語を付けずに書く。「目標を3,000円超えています」は事実(OK)。
  「3,000円も無駄遣いしました」は評価(NG)。

## 2. 事実 → 次にできること1つだけ

- 文の構成は必ず「事実(何が起きているか)」→「次にできること(1つだけ)」の順。
- 「次にできること」は必ず1つに絞る。複数の選択肢を並べない(選ぶのに迷わせない)。
- 状態が良い(余裕)ときも、「このまま」で終わらせず、具体的な数字(1日いくらまで、など)
  を伴う一言にする——順調さの言語化も「次にできること」の一種として扱う。
- 実装例:`src/domain/spending-plan.ts` の `forecastLine()`(N5で新設)。
  余裕(`on_track`)は「このペースなら目標内に収まりそうです。残り◯日は
  1日◯円まで使えます」、注意(`watch`/`over_pace`)は「…残り◯日は1日◯円まで
  に抑えると間に合います」、超過(`over`)は「目標を◯円超えています。残り◯日は
  これ以上増やさないのが目安です」。いずれも事実(見込み・超過額)→ 一言の行動
  (使える額の目安・抑える目安)の順で、選択肢は1つだけ。

## 3. 数字には必ず単位と期間を添える

- 金額は必ず「円」を付ける(`formatYen`/`formatSignedYen` を使い、生の数値を
  そのまま出さない)。
- 金額・割合には、**いつの/どの期間の数字か**を必ず添える(「今日」「今月」
  「残り◯日」「期間末」など)。「500円」だけでなく「今日あと500円」「残り3日は
  1日500円まで」のように書く。数字だけを裸で置かない。
- 割合(%)も対象期間を明示する(「今月の見直し候補比率 30%」など)。

## 4. 適用範囲

- 対象:`app/**/*.tsx` が画面に描画する文言(見出し・本文・ボタン・トースト・
  空状態・エラー表示)。
- 対象外:コード中のコメント・ADR/TASKS等のドキュメント・内部のドメイン変数名や
  型名・AIへのプロンプト(`src/prompts/`・`*-ai.ts` のAI向け指示文)・AIが
  生成する自由文の本文そのもの(AIの出力は `src/lib/ai-gateway` の数値検証を
  通すが、文体の強制はプロンプト側の指示に委ねる。将来的な改善課題)。
- 既存の大規模な機能名(「浪費/必要経費」診断、ADR-030・031)は本人発案の
  分類機能であり、内部名・ドメイン概念としては維持する。画面表示だけ
  「見直し候補」に統一する(上記1参照)。

## 5. 機械チェック

`tests/writing-rules.test.ts` が `app/**/*.tsx` の JSX が返す文字列
リテラル・テンプレートリテラルを走査し、禁止語(浪費・無駄・失敗・使いすぎ、
「〜すべきです」等の説教口調)が含まれていないかを検査する。コメント行は
対象外(上記4のとおり、コメントはルールの対象外のため)。
